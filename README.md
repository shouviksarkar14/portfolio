# Shouvik Sarkar · portfolio

Personal portfolio of Shouvik Sarkar, product manager. Plain HTML, no build step, hosted on Vercel.

| Path | What it is |
|---|---|
| `/` | Portfolio home |
| `/switchboard/` | Switch Board demo: my job-search tracker, running on sample data stored in the visitor's browser |
| `/casebook/` | Casebook Studio demo: interview cases as click-through decision trees, with 3 original cases |
| `/planner/` | IIMK course planner: elective timetable with live clash detection, substitutes, saved versions and exports |

The live Switch Board syncs from Gmail on a schedule and is private. The full Casebook Studio library is private.
